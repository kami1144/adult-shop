# 成人用品电商 MVP

面向日本市场的成人用品独立站，支持隐私发货。

**技术栈**：Next.js 14 (App Router) + TypeScript + Tailwind CSS

**线上地址**：待部署（Vercel）

---

## 页面结构

| 页面 | 路径 |
|------|------|
| 首页 | / |
| 产品列表 | /products |
| 产品详情 | /products/[id] |
| 购物车 | /cart |
| 结账 | /checkout |
| 关于我们 | /about |
| 联系合作 | /contact |

---

## 开发

```bash
npm install
npm run dev
```

---

## 品牌名占位符

全项目搜索替换 `[品牌名]` 即可一键替换为实际品牌。
